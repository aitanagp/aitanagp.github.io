Helpdesk Inteligente

Sistema de gestión de incidencias: Portal Web + App KMP (Android y Windows)

El Problema y la Solución

El objetivo de este proyecto es construir un sistema de gestión de incidencias (Helpdesk) con dos perfiles de cliente totalmente diferenciados, pero conectados a un único y potente backend centralizado.

Para el Empleado

Un Portal Web limpio y accesible donde el usuario puede abrir incidencias (con adjuntos), hacer seguimiento de su problema y comunicarse con soporte.

Para el Técnico IT

Una Aplicación de Escritorio y Móvil (desarrollada en Kotlin Multiplatform) desde donde recibe notificaciones push, se asigna tickets y gestiona las resoluciones.

Stack Tecnológico

Una arquitectura diseñada para ser robusta, escalable y preparada para integrar modelos de Inteligencia Artificial.

  • Backend & API: FastAPI (Python), SQLAlchemy 2. Estandarizado y rápido.
  • Base de Datos: PostgreSQL 16. Relacional y preparada para datos estructurados.
  • App Técnico: Compose Multiplatform (KMP) para Android y Windows.
  • Portal Web: HTML, CSS, JavaScript. Ligero y eficiente.
  • Infraestructura: Docker y Docker Compose. Despliegue en contenedores.

Estructura de Base de Datos

El núcleo relacional cuenta con las siguientes entidades principales, diseñadas para asegurar la trazabilidad:

Users: Empleados, Técnicos y Administradores.
Tickets (Incidencias): Categoría, prioridad, estado y tiempos.
Comments: Comunicación entre técnico y empleado (con modo "nota interna").
Attachments: Logs y capturas de pantalla de los errores.

Fases del Proyecto (Roadmap)

Fase 1: Cimientos y Backend

Configuración de contenedores Docker (PostgreSQL) y creación del sistema de usuarios, incidencias y roles con FastAPI.

Fase 2: Portal Web

Desarrollo de la interfaz web para empleados: creación de tickets y listado de estado.

Fase 3: App Técnico (KMP)

Desarrollo multiplataforma para gestionar colas de trabajo, asignar tickets y recibir notificaciones push/websockets.

Fase 4: Inteligencia Artificial (Próximamente)

Clasificación automática de tickets (categoría y prioridad) leyendo la descripción mediante NLP.
